# 네이버 블로그 자동화

관심 키워드나 주제를 넣으면 AI가 글감을 찾고 글을 쓰고 사진을 준비해서, 네이버 블로그 글쓰기 화면에
직접 타이핑하듯 입력해 발행까지 해주는 프로그램입니다. 사용자님 컴퓨터 안에서만 돌아갑니다.

## 시작하기 전에 확인할 것 두 가지

**명령어를 입력하는 창**을 열어주세요.
- 맥: `Command + 스페이스` → "터미널" 입력 → 엔터
- 윈도우: 시작 메뉴 → "터미널" 검색

아래 두 줄을 한 줄씩 붙여넣고 엔터를 눌러주세요.

```bash
node --version
claude --version
```

둘 다 숫자가 나오면 준비된 것입니다. 뭐라도 "찾을 수 없다"는 메시지가 나오면:
- `node`가 없으면 → https://nodejs.org 에서 LTS 버전을 받아 설치하세요.
- `claude`가 없으면 → Claude Code(이 프로그램을 만든 도구)를 먼저 설치하고 로그인해야 합니다.

## 앱 켜기

1. 이 폴더로 이동해서 필요한 프로그램을 내려받습니다 (처음 한 번만, 몇 분 걸립니다).

   ```bash
   npm install
   ```

2. 앱을 켭니다.

   ```bash
   npm run dev
   ```

3. 브라우저에서 **http://localhost:4123** 을 엽니다. 위쪽이 초록색인 화면이 뜨면 성공입니다.

   ⚠️ 명령어를 입력한 창은 **켜둔 채로** 두세요. 닫으면 앱이 꺼집니다.

## 네이버 로그인 (발행 전 한 번 필요)

네이버에 대신 글을 올리려면 로그인이 한 번 필요합니다. 화면 위쪽 **[네이버 로그인]** 버튼을 누르면
새 창이 뜹니다. 평소처럼 로그인하시면 되는데, **"로그인 상태 유지"에 꼭 체크**해 주세요. 체크하지
않으면 몇 시간 뒤 다시 로그인해야 하고, 읽기는 되는데 글쓰기만 막히는 헷갈리는 상태가 될 수 있습니다.

## (선택) AI로 사진 직접 그리기

사진을 검색해서 가져오는 대신 AI가 직접 그리게 할 수 있습니다. 저작권 걱정이 없다는 장점이 있습니다.
**하지 않아도 앱은 다 돌아갑니다** — 사진 검색이나 직접 찍은 사진으로도 충분합니다.

하시려면:
1. `env.sample` 파일을 복사해 `.env.local` 이라는 이름으로 만듭니다.
   - 맥/리눅스: `cp env.sample .env.local`
   - 윈도우: `copy env.sample .env.local`
2. Cloudflare 대시보드(Workers AI)에서 계정 ID와 API 토큰을 발급받아 `.env.local` 파일을 열어
   `CLOUDFLARE_ACCOUNT_ID=`, `CLOUDFLARE_API_TOKEN=` 뒤에 각각 붙여넣습니다.
3. 앱 켜기 창을 껐다가(`Ctrl+C`) 다시 `npm run dev` 로 켭니다.

무료 한도로 하루 30~40장 정도 생성할 수 있습니다(설정에서 품질을 조절하면 화면에 실시간으로
장수가 계산되어 보입니다).

## 처음 써보기 — 연습 모드

앱은 기본적으로 **연습 모드**입니다. 실제로 블로그에 올라가지 않고, 완성된 화면을 스크린샷으로만
저장합니다. 마음 놓고 눌러보세요.

1. 화면에서 원하는 유형(자동 발굴 / 체험단 / 브랜딩)을 고릅니다.
2. 내용을 채우고 **[연습으로 만들기]** 를 누릅니다.
3. 3~7분 정도 걸립니다. 중간에 브라우저 창이 저절로 열렸다 닫히는데 건드리지 마세요.
4. 다 되면 완성된 글과 사진이 화면에 보입니다.

## 실제로 올리기 (되돌릴 수 없습니다)

연습으로 만든 글이 마음에 들면 실제로 올릴 수 있습니다. **여기서부터는 되돌릴 수 없습니다.**

- 처음에는 **비공개**로 올려보시길 권합니다(설정에 이미 비공개로 되어 있습니다). 나만 볼 수 있어서
  결과를 확인한 뒤 나중에 공개로 바꿀 수 있습니다.
- 설정 서랍에서 **연습 모드**를 꺼야 실제로 발행됩니다.
- 하루 발행 수(기본 3편)와 발행 간격(기본 30분)은 계정 제재를 막기 위한 이 앱 자체의 안전장치입니다.
  네이버가 정한 값이 아니라 보수적으로 잡아둔 값이니, 필요하면 설정에서 조절할 수 있습니다.

## 알아두면 좋은 것

- 검색으로 가져온 사진은 저작권 분쟁 소지가 있습니다. 워터마크·인물 사진을 걸러내긴 하지만
  라이선스를 보장하지는 않습니다. 상업적으로 쓰기 전에는 직접 확인하세요. AI로 직접 그린 사진이
  더 안전한 선택지입니다.
- 수집한 뉴스·블로그 자료는 참고용입니다. 그대로 베끼지 않도록 AI에게 지시해두었지만, 결과물은
  발행 전에 한 번 읽어보시길 권합니다.
- 이 프로그램의 자동 발행은 네이버 이용약관상 계정 제재 위험이 있습니다. 그래서 연습 모드가
  기본값이고 안전장치들이 있는 것입니다. 이 안전장치들을 임의로 없애지 마세요.

## 문제가 생겼을 때

| 화면/메시지 | 뜻 | 어떻게 |
|---|---|---|
| Claude 표시등이 빨간색 | AI를 실행하는 프로그램이 준비되지 않음 | 위쪽 "시작하기 전에" 항목을 다시 확인하세요 |
| 네이버 표시등이 빨간색 | 로그인이 안 되어 있거나 만료됨 | [네이버 로그인]을 다시 누르고, "로그인 상태 유지"를 체크하세요 |
| 오늘 AI 사용량을 다 씀 | claude 구독 한도 도달 | 몇 시간 뒤 다시 시도하세요 |
| `EADDRINUSE :4123` | 앱이 이미 켜져 있음 | 새로 켜지 말고 http://localhost:4123 을 그냥 열어보세요 |

## 개발자용 참고

- 포트: 4123 (`next dev -p 4123`)
- 데이터: 전부 `./data` 폴더 안에 저장됩니다(SQLite, 로그인 세션, 이미지, 스크린샷). 삭제하면
  초기화됩니다.
- 검증 스크립트: `scripts/test-*.ts` (계정 불필요), `scripts/harness-editor.ts` (로그인 전 에디터
  입력 순서 검증, 9장 6.5-a). `npx tsx scripts/<파일명>.ts` 로 실행합니다.
- 네이버 에디터 셀렉터는 `lib/scrape/selectors.ts` 한 곳에 모여 있습니다. 네이버가 화면을 바꿔
  셀렉터가 깨지면 이 파일만 고치면 됩니다.
